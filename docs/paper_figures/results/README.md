# Paper-Ready Result Figures for the BRACE/KBS Manuscript

This directory stores selected result-oriented figures that are suitable for the current BRACE manuscript and easy to reuse in paper materials or presentation slides.

## Included figures

| File | Manuscript role | Notes |
|---|---|---|
| `fig5_qualitative_comparison.png` | Qualitative comparison | Representative qualitative mask comparison with baseline methods and BRACE. |
| `fig6_component_effect_summary.png` | Component-effect visualization | Visual summary derived from the ablation table for BUSI 1/8 and TN3K 1/8. |
| `fig7_failure_cases.png` | Limitation / failure analysis | Representative remaining difficult cases used to support the limitation section. |

## Selection notes

- These are the result/experiment-oriented figures retained for reuse outside the canonical submission package.
- The canonical KBS submission source uses the revised BRACE figures archived under `docs/kbs_submission_package/source/`.
- Intermediate figure variants are intentionally excluded from the submission package.
