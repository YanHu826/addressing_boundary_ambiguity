# BRACE KBS Submission Archive

This directory is a Git-tracked copy of the local Knowledge-Based Systems
submission package for BRACE, archived so the manuscript assets remain available
after the workspace is removed.

Key files:

- `manuscript/BRACE_KBS_manuscript.pdf`: final compiled manuscript PDF.
- `source/cas-dc-template_BRACE_fixed.tex`: canonical LaTeX source.
- `source/cas-refs.bib`: bibliography database.
- `source/*.png`: manuscript figures and result visualizations.
- `cover_letter/BRACE_KBS_cover_letter.pdf`: compiled cover letter.
- `cover_letter/Cover Letter.tex`: cover letter source.
- `highlights/BRACE_highlights.txt`: Elsevier highlights file.
- `README_SUBMISSION.txt`: rebuild instructions.

Result and figure assets included in `source/`:

- `compare.png`
- `component_effect_summary.png`
- `failure_cases.png`
- `intro_lesion_variants.png`
- `sorp_rct_module.png`
- `user_fbwa_module_notitle.png`
- `user_overall_framework_notitle.png`

Intermediate figure assets are intentionally not archived because the canonical
manuscript now uses the revised BRACE/FBWA/RCT figures listed above.
